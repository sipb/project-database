Potential (DRAFT) structure & ideas of projectdb

- Remove "roles" - it's not really used, and joining a project shouldn't be defined by "being assigned a role".
    - Roles seem to imply you must already have the particular skill, rather than learning and eventually contributing
    - Shouldn't phrase as "looking for..." but rather "you'll learn about..."

- Have a tier system for project memberships
    - Interested: Expressed interest in learning more about the project and that should be onboarded by project members
    - Learning Member: Has been onboarded and is in the process of learning about how the project works and developing the knowledge to be able to contribute independently
    - Project Member: Familiar with the project, can contribute indenpendently, and can help other members understand it.

- Tagging system for projects
